## 3. Seguridad de los EAs (obligatoria)

Implementadas dos reglas que se aplican a TODO EA futuro:

### Filtro de noticias (5%ers requirement)
- API MQL5 `CalendarValueHistory` + `CalendarEventById`
- Bloquea trades ±2 min de noticias alto impacto
- Inputs: `UseNewsFilter=true`, `NewsWindowMin=2`

### Circuit breakers (proteccion fondeo)
- DD diario >3% → pausa hasta siguiente día
- 3 SL consecutivos → bloqueo del día
- Inputs: `UseCircuitBreakers`, `DailyDDPause=3`, `ConsecutiveSLs=3`
